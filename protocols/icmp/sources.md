# ICMP (IPv4): sources

Hierarchy: standards (RFC, IANA) > official vendor documentation > references.
Accessed 6 November 2026. Same list and numbering as the Sources chapter of `index.html`.

1. **RFC 792, Internet Control Message Protocol (STD 5)**: whole document: message formats, types and codes; updated by RFC 950, 4884, 6633 and 6918. https://www.rfc-editor.org/rfc/rfc792
2. **RFC 1122, Requirements for Internet Hosts: Communication Layers (STD 3)**: §3.2.2 (ICMP: when not to send an error, each message type), §3.2.2.6 (Echo), §3.3.1.2 (redirects and the route cache), §4.1.3.3 (UDP and ICMP errors), §4.2.3.9 (TCP and ICMP errors). https://www.rfc-editor.org/rfc/rfc1122
3. **RFC 1812, Requirements for IP Version 4 Routers**: §4.3.2.2 to §4.3.2.8 (TTL, quoted datagram, source address, precedence, when not to send, rate limiting), §4.3.3 (each message type), §5.2.7 (Destination Unreachable, Redirect, Time Exceeded), §5.3.1 (TTL). https://www.rfc-editor.org/rfc/rfc1812
4. **RFC 1191, Path MTU Discovery**: §3 (host), §4 (router, Next-Hop MTU field), §5 (old-style messages), §6.3 (ageing of the estimate), §7.1 (plateau table). https://www.rfc-editor.org/rfc/rfc1191
5. **RFC 4884, Extended ICMP to Support Multi-Part Messages**: §4 (length attribute), §5 (backwards compatibility), §7 (extension header), §8 (extension objects). https://www.rfc-editor.org/rfc/rfc4884
6. **RFC 4950, ICMP Extensions for Multiprotocol Label Switching**: §2 (MPLS Label Stack object), §3 (IANA). https://www.rfc-editor.org/rfc/rfc4950
7. **RFC 6633, Deprecation of ICMP Source Quench Messages**: §3 to §6. https://www.rfc-editor.org/rfc/rfc6633
8. **RFC 6918, Formally Deprecating Some ICMPv4 Message Types**: §2, §3. https://www.rfc-editor.org/rfc/rfc6918
9. **RFC 1256, ICMP Router Discovery Messages**: §3 (message formats), §4.1 (router configuration variables). https://www.rfc-editor.org/rfc/rfc1256
10. **RFC 5927, ICMP Attacks against TCP**: §4 (general counter-measures), §5 (blind connection reset), §6 (blind throughput reduction), §7 (blind performance degrading). https://www.rfc-editor.org/rfc/rfc5927
